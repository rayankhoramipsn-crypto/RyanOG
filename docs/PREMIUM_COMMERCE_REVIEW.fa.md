# گزارش بازطراحی TRISOCMD

شاخه: `feat/premium-gaming-commerce` — [PR پیش‌نویس شماره ۴](https://github.com/rayankhoramipsn-crypto/RyanOG/pull/4).

کد واقعی سایت در مسیرهای اصلی و `preview/` اصلاح شده است. **سایت اصلی منتشر نشده، دیتابیس Production تغییر نکرده و پرداخت واقعی فعال نشده است.**

## بخش‌های پیاده‌سازی‌شده

- سیستم طراحی مشترک زغالی/بنفش، هدر و منوی موبایل، کارت‌ها و فرم‌های هماهنگ، Skeleton، وضعیت خالی/خطا و تلاش دوباره، فوکوس کیبورد، Lightbox و رعایت Reduced Motion.
- فروشگاه با محصولات واقعی، جست‌وجو، دسته‌بندی، مرتب‌سازی و مجموعه‌های ویژه، جدیدترین‌ها، پرفروش‌ها و پیشنهادها. این مجموعه‌ها از داده بک‌اند تغذیه می‌شوند و با محصول یا آمار ساختگی پر نشده‌اند.
- مدیر می‌تواند محصول ویژه و قیمت پیشین واقعی را تنظیم کند. پرفروش‌ها با اقدام مدیر فقط از تعداد کالاهای سفارش‌های پرداخت‌شده/تحویل‌شده سامانه فعلی محاسبه می‌شوند؛ سفارش در انتظار پرداخت شمرده نمی‌شود و هیچ سفارش یا پرداختی تغییر نمی‌کند.
- صفحه محصول با گالری و بزرگ‌نمایی، مشخصات فنی، ویدیو یوتیوب معتبر، محصولات مرتبط، محدودیت تعداد و سبد محلی. مشکل نمایش‌ندادن مشخصات و تداخل متغیر `URL` اصلاح شده است.
- مارکت‌پلیس با فیلتر و مرتب‌سازی، ثبت و بررسی آگهی، حفظ پیام‌رسانی موجود، آپلود خصوصی حداکثر شش تصویر، نمایش/حذف تصویر و تکمیل آپلود ناقص آگهی در انتظار تأیید.
- پروفایل عمومی اختیاری فروشنده و صفحه `seller.html` با آگهی‌های تأییدشده. انتشار فقط با انتخاب فروشنده و داشتن آگهی تأییدشده مجاز است؛ ایمیل و اطلاعات حساب خصوصی منتشر نمی‌شوند.
- پنل مدیریت با Sidebar، بررسی آگهی و گالری، تغییر نام دسته‌بندی، تنظیم مجموعه‌های ویژه و آمار فروش، نمایش سفارش‌ها/تیکت‌ها و پیوند مدیریت رسانه/مشخصات. مدیریت محصولات و صندوق پاسخ پشتیبانی موجود حفظ شده‌اند.
- وبلاگ با جست‌وجو، دسته‌بندی، صفحه مطالعه، تصویر جلد، مقالات مرتبط، متادیتا و داده ساختاریافته Article و ویرایشگر پیش‌نویس/انتشار. متن مقاله بدون اجرای HTML/اسکریپت نمایش داده می‌شود.
- رابط EN/FA/AR، تغییر RTL/LTR، تنظیم زبان مشترک بین صفحات و ترجمه بخش حساب. متن تألیفی محصولات و مقاله‌ها خودکار ترجمه نمی‌شود؛ بعضی خطاهای پویای سرویس‌های قدیمی ممکن است انگلیسی بمانند.
- بازیابی و تمدید نشست صفحات محتوا با بررسی کاربر توسط Auth. کنترل دسترسی واقعی در بک‌اند و RLS است، نه مخفی‌کردن دکمه‌ها.
- انتشار GitHub Pages دستی و وابسته به موفقیت تست‌ها شده است؛ Push یا Merge سایت را منتشر نمی‌کند. Workflow پیش‌نمایش فقط Artifact قابل دانلود می‌سازد.

## تغییرات دیتابیس

افزونه Supabase در این جلسه در دسترس بود. دو Migration افزایشی فقط روی پروژه آزمایشی `cxtytbjvdlngahytfilr` اعمال شدند:

1. `20261030193709_marketplace_private_gallery.sql`: جدول گالری، ایندکس‌ها، RLS و مخزن خصوصی تصاویر با محدودیت نوع/حجم. مالک و مدیر تصاویر در انتظار تأیید را می‌بینند؛ پس از تأیید، خواندن عمومی با پیوند امضاشده پنج‌دقیقه‌ای ممکن است. فروشنده پس از تأیید اجازه تغییر گالری ندارد.
2. `20261030201414_commerce_merchandising_and_public_sellers.sql`: تنظیمات نمایش محصول، Snapshot تعداد فروش، پروفایل عمومی با انتشار اختیاری و RPC محاسبه آمار با SECURITY INVOKER و بررسی مدیر. اطلاعات خصوصی مشتری و سفارش منتشر نمی‌شوند.

Migrationها روی staging قبلاً اعمال شده‌اند؛ دوباره اجرا نکنید و بدون بررسی و مجوز روی Production اعمال نکنید. مخزن شامل Migrationهای پایه قدیمی نیست و نصب دیتابیس از صفر را پوشش نمی‌دهد. هیچ داده نمایشی برای مجموعه‌ها، آمار یا پروفایل‌ها Seed نشده است.

## تست‌های انجام‌شده

- ۱۱ بررسی ثابت مسیرها، دارایی‌ها، noindex، امنیت، همگامی root/preview و انتشار دستی: موفق.
- بررسی نحوی ۲۹ منبع JavaScript: موفق.
- ۱۵ سناریوی Chromium روی preview و مسیرهای اصلی: موفق؛ شامل مجموعه‌ها، جست‌وجو و مرتب‌سازی، سه زبان و عرض ۳۶۰ تا ۱۴۴۰ پیکسل، گالری و مشخصات، سبد، وبلاگ و XSS، ثبت/آپلود، پروفایل عمومی، خروج، مجوز مدیر، انتشار مقاله، تأیید آگهی، تنظیم پیشنهادها و آمار، قطع اتصال و Reduced Motion.
- داده‌های مرورگر فقط Fixture تست بودند؛ این آزمون‌ها معادل ورود یا آپلود HTTP واقعی به Supabase نیستند.
- دو آزمون SQL واقعی در staging: دسترسی مالک/کاربر دیگر/مهمان به گالری، محدودیت پس از تأیید، خصوصی‌بودن پروفایل پیش از انتخاب انتشار و تأیید آگهی، جلوگیری از تغییر تنظیمات توسط مشتری و محاسبه فقط سفارش‌های پرداخت‌شده. در آزمون، ۲ واحد پرداخت‌شده شمرده و ۹۹ واحد در انتظار پرداخت نادیده گرفته شد.
- تمام کاربران، محصولات، آگهی‌ها، سفارش‌ها و تغییرات آمار تست در پایان تراکنش بازگردانده شدند. بررسی بعدی، باقی‌ماندن صفر محصول/آگهی تست و خالی‌بودن داده‌های نمایشی جدید را تأیید کرد.
- تنظیم Storage، سیاست‌ها، سابقه Migration، مشاور امنیت Supabase و `git diff --check` بررسی شدند. هشدار امنیتی جدیدی از نوع SECURITY DEFINER به تغییرات اضافه نشد.

## موارد باقی‌مانده پیش از انتشار

آزمون زنده ورود، بازیابی رمز، ایمیل، JWT واقعی، آپلود/دانلود Storage و پیام‌رسانی چندکاربره هنوز لازم است. محیط فعلی HTTP پروژه Supabase را مجاز نمی‌کند. میزبان `cxtytbjvdlngahytfilr.supabase.co` باید در تنظیمات شبکه محیط مجاز شود، حساب‌های موقت مشتری/فروشنده/مدیر از طریق Secret Manager فراهم شوند و مبدأ staging در Site URL و Redirect allowlist بخش Auth تنظیم شود. آزمون ایمیل نیز به ارائه‌دهنده ایمیل تنظیم‌شده نیاز دارد. رمز دیتابیس و دسترسی Production برای این جریان‌ها لازم نیست.

سایت همچنان noindex است؛ نشانی‌های ازپیش‌رندرشده، canonical/sitemap و شرایط حقوقی نهایی به مرحله انتشار جداگانه نیاز دارند. سامانه‌های قدیمی موازی سفارش/پشتیبانی حفظ شده‌اند؛ تحویل خودکار، پرداخت واقعی، اسکن محتوای فایل، محدودیت نرخ/حجم مصرف سمت سرور و پاک‌سازی فایل‌های خصوصی بی‌ارتباط هنوز عملیاتی نشده‌اند. آمار فروش به به‌روزرسانی مدیر نیاز دارد.

هشدارهای قبلی [اجرای عمومی SECURITY DEFINER](https://supabase.com/docs/guides/database/database-linter?lint=0028_anon_security_definer_function_executable)، [اجرای آن توسط کاربران واردشده](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable) و [غیرفعال‌بودن محافظت رمزهای افشاشده](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection) باقی است و باید پیش از فعال‌سازی Production بررسی شود.

## فایل‌ها و پیش‌نمایش

مسیرهای اصلی `index.html`، `product.html`، `marketplace.html`، `seller.html`، پوشه‌های `admin/`، `blog/`، `help/`، `policies/`، `videos/` و نسخه‌های همسان آن‌ها در `preview/`؛ ماژول‌های طراحی، ترجمه، نشست، مجموعه‌ها، فروشندگان، مدیریت و گالری در `assets/`؛ دو Migration؛ تست‌های `tests/`؛ سه Workflow؛ Package/Lockfile؛ اسکریپت همگامی و گزارش‌ها تغییر کرده‌اند. فهرست کامل در [گزارش فنی](PREMIUM_COMMERCE_REVIEW.md) است.

برای بررسی محلی:

```sh
npm ci
npx playwright install chromium
npm test
python3 -m http.server 4173
```

`http://localhost:4173/` یا `/preview/` را باز کنید. بعد از ویرایش فایل‌های اصلی، `npm run sync:preview` نسخه آزمایشی را همگام می‌کند. پیش‌نمایش عمومی منتشر نشده است؛ Artifact کامل از Workflow «Build staging preview artifact» قابل دریافت خواهد بود. انتشار نهایی نیازمند تکمیل موارد بالا و مجوز جداگانه است.
